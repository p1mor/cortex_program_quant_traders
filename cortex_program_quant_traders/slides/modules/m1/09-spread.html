Bid-Ask Spread

Formación del precio · coste de cruce
Estación de formación del precio Libro · ejecución · referencia

El spread es el costo implícito de cruzar el libro. Cada vez que ejecutas una orden de mercado, pagas la diferencia entre el mejor ask y el mejor bid.

ASK 5,488.25
Corredor Spread 0.25
BID 5,488.00
Bid

Mayor precio actualmente ofrecido para comprar.

Ask

Menor precio actualmente ofrecido para vender.

Last

Precio de la última transacción ejecutada.

No existe solamente un precio. En cada instante existen, como mínimo, tres referencias fundamentales: Bid, Ask y Last.
